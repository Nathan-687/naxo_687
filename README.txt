## Prévisualiser
Ouvre `index.html` dans un navigateur.

## Publier gratuitement avec GitHub Pages
1. Connecte-toi à GitHub et crée un nouveau dépôt public, par exemple `naxo-687`.
2. Envoie le fichier `index.html` à la racine du dépôt (Add file → Upload files → Commit changes).
3. Dans le dépôt, ouvre Settings → Pages.
4. Dans Build and deployment, choisis Deploy from a branch, puis `main` et `/ (root)`, et sauvegarde.
5. Après le déploiement, GitHub affichera une adresse de la forme `https://TON-PSEUDO.github.io/naxo-687/`.

Pense à modifier le bouton « Voir le profil public » dans `index.html` pour y mettre l'URL réelle de ton profil. La page est un portrait promotionnel et ne prétend pas être une couverture de presse indépendante.
